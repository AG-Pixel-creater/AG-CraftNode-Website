AG CraftNode

Create, configure and run your own local Minecraft server from a single desktop app — Java setup, plugins, tunnels and all. Works with cracked Minecraft clients.

AG CraftNode
v0.0.1 Setup EXE 27 MB Windows 10 / 11
Download AG CraftNode AG_CraftNodeSetup.exe · v0.0.1 — free

Run AG_CraftNodeSetup.exe and the installer sets everything up. Java runtimes, server JARs and tunnel tools are downloaded automatically by the app on first run.

Prefer the Python source? Grab the portable ZIP — needs Python 3.8+ and pip install PyQt6.
